# Исходники схем

Схемы на страницах стоят встроенным SVG: страница обязана работать из `file://` и без внешних файлов, а встроенный вектор наследует цвет темы через `currentColor` и переживает переключение день/ночь без второй копии картинки.

Здесь лежат исходники тех же схем на языке Mermaid. **Рендерера Mermaid в парке нет** (`mmdc` не установлен), поэтому SVG на страницах нарисован вектором руками по этому исходнику, а не снят с него автоматически. Исходник хранится ровно для того, чтобы схему можно было пересобрать, когда вьювер или рендерер появятся: тогда `.mmd` станет источником, а SVG - производным.

Соответствие:

| Исходник | Страница | Что показывает |
| :-- | :-- | :-- |
| `01-reconcile.mmd` | `ru/01.html` | путь изменения вниз и путь фактического состояния вверх |
| `02-object.mmd` | `ru/02.html` | анатомия объекта: кто пишет какое поле |
| `03-pod.mmd` | `ru/03.html` | песочница пода и порядок запуска контейнеров |
| `04-rollout.mmd` | `ru/04.html` | деплоймент, два набора реплик и ход раскатки |
| `05-capacity.mmd` | `ru/05.html` | вместимость узла: запросы против фактического потребления |
| `06-service.mmd` | `ru/06.html` | сервис, срез адресатов и готовность |
| `07-storage.mmd` | `ru/07.html` | под, заявка, носитель и класс хранения |
| `08-admission.mmd` | `ru/08.html` | путь запроса через API-сервер |
| `09-failures.mmd` | `ru/09.html` | состояние пода и вставший контур |
